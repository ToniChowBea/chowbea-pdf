# Chowbea PDF — web

The frontend for [pdf.chowbea.com](https://pdf.chowbea.com): a TanStack Start
app (React 19, Vite, Tailwind, shadcn/ui, hugeicons) that runs on bun. It talks
to the FastAPI backend in [`../api`](../api). See the [root README](../README.md)
for the full local setup, including RabbitMQ and the API's system dependencies.

## Quick start

```bash
bun install
bun run dev        # http://localhost:3000
```

The app expects the API on `http://localhost:8000`. From the repo root,
`make dev` starts both together.

## Configuration

| Variable | Default | Notes |
| --- | --- | --- |
| `VITE_API_URL` | `http://localhost:8000` | Base URL of the API. Vite inlines it at **build** time, so the Docker image takes it as a build arg (`--build-arg VITE_API_URL=...`), not a runtime env var. |

## Scripts

| Command | What it does |
| --- | --- |
| `bun run dev` | Dev server on port 3000 |
| `bun run build` | Production build into `.output/` |
| `bun run start` | Serve the production build (`bun .output/server/index.mjs`) |
| `bun run test` | Vitest suite |
| `bun run typecheck` | `tsc --noEmit` |
| `bun run lint` | ESLint |
| `bun run check` / `bun run format` | Prettier check / write |
| `bun api:generate` | Regenerate the typed API client once |
| `bun api:watch` | Regenerate the client whenever the API spec changes |
| `bun run dev:all` | `api:watch` and `dev` side by side |

CI runs `bun install --frozen-lockfile`, `test`, `typecheck` and `build`, so
run those before opening a pull request.

## Layout

- `src/routes/` — one file per page: `index`, `compress`, `lock`, `unlock`,
  `merge`, `split`, `rotate`, `convert`, and the public `queue` board.
  `src/routeTree.gen.ts` is generated by the router plugin; don't edit it.
- `src/lib/` — API helpers (`api.ts`) and the shared submit → poll → download
  job flow (`jobs.ts`), plus small tested utilities.
- `src/components/` — app components; `src/components/ui/` holds shadcn/ui
  components.
- `src/services/api/_generated/` — typed client generated by
  [chowbea-axios](https://github.com/ToniChowBea/chowbea-axios) from
  `http://localhost:8000/openapi.json` (settings in `api.config.toml`). Don't
  edit it by hand; run `bun api:generate` with the API running instead.

## Adding a shadcn/ui component

```bash
bunx shadcn@latest add button
```

This writes to `src/components/ui/`; import it with
`import { Button } from "@/components/ui/button"`.
